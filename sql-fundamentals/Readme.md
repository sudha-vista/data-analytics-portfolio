# Student Result Database Project

## Overview
A simple SQL-based project to store and analyze student academic results using relational database concepts.

## Database Structure
- **students**: student_id, name, department, semester  
- **results**: result_id, student_id, subject, marks  

## Key Features
- Student-wise marks (JOIN)
- Average marks per student
- High scorers filtering (>80)
- Department-wise performance
- Top scorer identification

## Technologies
- SQL (SQLite)

## Usage
Run `student_result_database.sql` in any SQL environment to create tables, insert data, and execute queries.
