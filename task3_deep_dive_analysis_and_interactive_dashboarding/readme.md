# deep-dive analysis & interactive dashboarding 

## Project Overview
**Retail Sales Interactive Dashboard** is an Excel-based dashboard developed to analyze retail sales performance using interactive visualizations and key business metrics. It provides insights into sales trends, top-performing products, and sales by location, helping support data-driven decision-making.


## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Dashboard Highlights
- Total Sales
- Total Orders
- Average Order Value
- Sales by Product
- Sales by Location
- Monthly Sales Trend
