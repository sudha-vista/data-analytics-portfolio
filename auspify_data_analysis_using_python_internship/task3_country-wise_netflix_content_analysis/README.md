# Task 3 - Country-Wise Netflix Content Analysis

## Internship
Data Analysis Using Python Internship

## Objective

The objective of this task is to analyze Netflix content availability across different countries. The analysis identifies the countries with the highest number of Netflix titles using Python.

## Dataset

The Cleaned netflix dataset from Task 1 was used for this analysis.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## Work Done

- Loaded the cleaned Netflix dataset.
- Extracted and cleaned country information.
- Separated multiple countries associated with the same title.
- Calculated the number of titles for each country.
- Identified the top content-producing countries.
- Created a country-wise ranking.
- Created a bar chart for the top 10 countries.
- Summarized the key findings.

## Key Findings

- The United States is one of the major content-producing countries in the dataset.
- The top countries have a large number of Netflix titles.
- The country-wise ranking shows the difference in content availability across countries.
- The bar chart makes it easy to compare the top content-producing countries.

## Files

- `country_wise_content_analysis.ipynb` - Python notebook containing the analysis.
- `cleaned_netfilx_dataset.csv` - Cleaned dataset used for the analysis.

## Conclusion

The analysis shows the distribution of Netflix content across different countries. The top content-producing countries were identified and compared using rankings and visualization.
