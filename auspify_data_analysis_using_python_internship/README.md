# Task 4 - Trend Analysis by Release Year  
  
## Internship  
Data Analysis Using Python Internship  
  
## Objective  
  
The objective of this task is to analyze Netflix content production over different release years. The analysis identifies yearly content trends and changes in the number of titles released.  
  
## Dataset  
  
The Cleaned netflix dataset from Task 1 was used for this analysis.  
  
## Tools and Technologies  
  
- Python  
- Pandas  
- Matplotlib  
- Google Colab  
  
## Work Done  
  
- Loaded the cleaned Netflix dataset.  
- Explored the Release_Year column.  
- Calculated the number of titles released in each year.  
- Identified the years with the highest number of titles.  
- Created a yearly content trend.  
- Created a line chart to visualize the trend.  
- Compared changes in content production over the years.  
- Summarized the key findings.  
  
## Key Findings  
  
- Netflix content production varies across different release years.  
- Some years have a higher number of titles compared to others.  
- Recent years show a higher amount of content compared to many earlier years.  
- The line chart clearly shows changes in content production over time.  
  
## Files  
  
- `trend_analysis_by_release_year.ipynb` - Python notebook containing the analysis.  
- `cleaned_netfilx_dataset.csv` - Cleaned dataset used for the analysis.  
  
## Conclusion  
  
The analysis shows how Netflix content production has changed across different release years. The yearly counts and trend visualization provide a clear view of the changes in content production over time.
