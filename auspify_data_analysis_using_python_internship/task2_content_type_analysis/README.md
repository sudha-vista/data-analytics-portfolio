# Task 2 - Content Type Analysis

## Internship
Data Analysis Using Python Internship

## Objective

The objective of this task is to analyze the distribution of Movies and TV Shows available on Netflix. The analysis compares the number and proportion of each content type using Python.

## Dataset

The cleaned Netflix dataset from Task 1 was used for this analysis.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

## Work Done

- Loaded the cleaned Netflix dataset.
- Analyzed the content types available in the dataset.
- Calculated the number of Movies and TV Shows.
- Calculated the percentage of each content type.
- Created a bar chart to compare Movies and TV Shows.
- Created a pie chart to show their proportions.
- Identified the most common content type.
- Summarized the key findings.

## Key Findings

- Movies are more common than TV Shows in the dataset.
- Movies make up the larger share of the total content.
- TV Shows represent a smaller share compared to Movies.
- The charts clearly show the difference between the two content types.

## Files

- `content_type_analysis.ipynb` - Python notebook containing the analysis.
- `cleaned_netfilx_dataset.csv` - Cleaned dataset used for the analysis.

## Conclusion

The analysis shows that Movies make up the majority of the content in the Netflix dataset, while TV Shows account for a smaller portion. The visualizations provide a clear comparison between the two content types.
