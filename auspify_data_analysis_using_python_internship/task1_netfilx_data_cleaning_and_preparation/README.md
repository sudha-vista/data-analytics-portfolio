
# Task 1: Netflix Data Cleaning and Preparation

## Project Overview

This project focuses on preparing the Netflix dataset for analysis using Python and Pandas. The dataset was explored, checked for data quality, and prepared for future analysis by standardizing column names, converting data types, and exporting the final dataset.

---

## Objective

- Import the Netflix dataset.
- Explore the dataset structure.
- Check for missing values and duplicate records.
- Standardize column names.
- Convert the `Date_Added` column to the datetime format.
- Export the prepared dataset.

---

## Technologies Used

- Python
- Pandas
- Google Colab

---

## Files Included

- `netflix_data_cleaning_and_preparation.ipynb` – Jupyter Notebook containing the complete workflow.
- `dataset.csv` – Original Netflix dataset.
- `cleaned_netflix_dataset.csv` – Prepared dataset after preprocessing.

---

## Project Workflow

1. Import Required Libraries
2. Load the Dataset
3. Explore the Dataset
4. Check Data Quality
5. Standardize Column Names
6. Convert Data Types
7. Export the Prepared Dataset

---

## Results

- Successfully loaded and explored the dataset.
- No missing values or duplicate records were found.
- Column names were standardized.
- The `Date_Added` column was converted to the datetime format.
- The prepared dataset was exported successfully.
