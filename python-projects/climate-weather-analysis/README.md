# Climate Weather Analysis

## Project Overview
This project analyzes weather data to explore patterns in temperature and rainfall.  
The analysis includes data cleaning, feature engineering, visualization, and extracting insights from the dataset using Python.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset contains weather records including:
- Date
- City
- Temperature
- Rainfall

Files included in this project:
- weather.csv – original dataset
- clean_weather.csv – cleaned dataset
- weather_analysis.ipynb – complete analysis notebook

## Analysis Steps
- Load and explore the dataset
- Handle missing temperature values
- Convert date column to datetime format
- Create new features such as month and season
- Sort data by date for time-based analysis
- Visualize temperature and rainfall trends
- Identify extreme rainfall days and hottest days

## Visualizations
The analysis includes multiple charts:
- Rainfall trend over time
- Temperature trend over time
- Temperature vs Rainfall scatter plot
- Daily temperature bar chart
- Daily rainfall bar chart
- Combined temperature and rainfall trend

## Key Insights
- Weather data shows clear seasonal patterns.  
- Some days are significantly hotter than others.  
- Heavy rainfall events are rare but noticeable.
