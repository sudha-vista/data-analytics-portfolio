Data immersion and wrangling 

##  Project Overview

This project focuses on **data cleaning and preprocessing** of a retail sales dataset using Python.
The goal is to transform raw data into a clean and structured format for further analysis and visualization.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Google Colab / Jupyter Notebook

---

## Dataset

* File: `retail_sales_dataset.csv`
* Contains information such as:

  * Order ID
  * Transaction Date
  * Client Name
  * Product Name
  * Location
  * Sales Amount

---

## Data Cleaning Summary

* Standardized column names for consistency
* Handled missing values using appropriate techniques 
* Removed duplicate records
* Detected and treated outliers
* Ensured overall data quality and consistency

---

##  Outcome

* Clean and structured dataset ready for analysis
* Improved data quality and reliability
